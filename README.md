Free Google Play promo codes for [Folkplay](https://play.google.com/store/apps/details?id=com.mcs2k8.folkplay) — 160+ classic and folk games (Durak, Pogs, marbles, a retro brick game and more), offline and without ads.

**Claim a code:** https://mcs2k8.github.io/folkplay-promo/
